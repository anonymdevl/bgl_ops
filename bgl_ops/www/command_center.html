Monthly Payroll Prep Sheet

loans + advances + absences + new hires + allowances

Loans pre-fill from the ledger, advances carry forward from last month, absences are entered as days (the payslip computes the money). One Save writes the ledger and every draft deduction.

Choose a month, then Load Sheet.

How it flows: loan rows write ledger repayments + draft "Loans" deductions; advances become draft "Salary Advance" deductions (deducted in full this month); absent days become draft "Absent" deductions - amount ((days/22) x Basic) computed automatically. All drafts dated to month-end - review under Additional Salary, then run Payroll Entry.
